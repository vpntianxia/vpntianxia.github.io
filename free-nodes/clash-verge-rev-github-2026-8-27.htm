一、什么是Shadowrocket？

Shadowrocket 是一款专为 iOS 平台打造的网络代理工具，功能强大且配置灵活，主要用于设置代理、实现加密流量转发，从而突破地域或网络限制，同时保障用户的上网安全与隐私。

其核心特点如下：

  • 协议支持广泛：支持 Shadowsocks、Vmess、Trojan、HTTP、HTTPS、SOCKS5 等多种协议；

  • 规则灵活：可自定义规则分流，按域名/IP/应用进行流量分类管理；

  • 流量统计详细：实时监控上传/下载速度，帮助用户精确了解网络使用情况；

  • IPv6支持完善：适配现代网络环境；

  • 兼容订阅功能：一键导入节点，动态更新配置文件，极大方便用户维护节点列表。

对于追求隐私、自由、性能的iOS用户来说，Shadowrocket几乎是必不可少的工具。

三、Shadowrocket的基础配置教程

1. 添加代理节点

Shadowrocket支持手动输入节点或通过订阅链接一键导入节点列表。推荐使用订阅链接方式，便于统一管理与自动更新。

方法一：手动添加

  • 打开Shadowrocket；

  • 点击右上角“+”图标 → 选择节点类型（如Shadowsocks、Vmess等）；

  • 填入服务器信息：地址、端口、密码、加密方式等；

  • 保存后即可看到节点出现在列表中。

方法二：使用订阅链接导入

  • 获取订阅地址（如Clash牧场或Telegram群中分享的）；

  • 打开Shadowrocket → 点击“配置” → 添加配置 → 输入订阅URL；

  • 命名后保存，并点击右上角刷新按钮同步节点。

多数节点提供商都会提供兼容Shadowrocket的专用链接。

2. 设置规则分流（可选）

Shadowrocket支持多种代理模式：

  • 全局代理：所有流量均通过代理；

  • 规则模式：按域名/IP或国家归属进行智能分流；

  • 绕过大陆地址：国内流量直连，境外流量代理。

你可以通过添加公共规则集（如ACL4SSR）来自动化管理：

  • 打开“配置”；

  • 点击“规则” → “远程规则”；

  • 添加远程规则地址（例如GitHub上的规则订阅）；

  • 启用该规则配置。

3. 启用代理

  • 配置完成后，返回主界面；

  • 点击右上角开关按钮，首次启用会提示添加VPN配置；

  • 点击“允许”，输入设备密码，授权后将自动建立VPN隧道；

  • 状态栏显示VPN图标，即表示代理已启动成功。

四、使用技巧与进阶配置

✅ 配合第三方DNS使用

推荐搭配 DoH（DNS over HTTPS）服务，如Cloudflare的 1.1.1.1，增强域名解析隐私性与准确性。

路径：设置 → DNS → 添加 → 选择 DoH → 输入地址。

✅ 绑定特定应用使用代理

可开启“分应用代理”模式，仅对部分App启用代理，如YouTube、Telegram等，节省流量并提高效率。

路径：设置 → 应用规则 → 添加 → 选择App → 指定代理方式。

✅ 实时测速与节点切换

长按某个节点可进行测速，数值越小表示连接延迟越低；推荐根据延迟情况选择速度最佳节点。

✅ 多配置切换

支持保存多个配置文件，适用于不同场景（如工作/娱乐/旅行），在主界面一键切换。

FAQ

Hiddify Next 的多机场订阅如何整合？
Hiddify Next 提供合并订阅功能，可将多个链接导入同一配置，自动去重并分类节点。用户可设置优先级与标签，方便快速选择不同提供商的线路，提升连接灵活性与冗余度。
Trojan 节点如何正确配置证书？
TLS 证书必须有效且域名匹配，否则客户端无法建立连接。建议使用受信任证书并确保证书链完整，可保证节点安全和长期可用性，同时提高伪装效果和抗封锁能力。
Trojan 的伪装域名选择有哪些原则？
伪装域名必须是真实可访问网站，并且证书有效。这样可以让 Trojan 流量看起来像普通 HTTPS 请求，减少被封锁或 DPI 检测风险，确保节点安全和可用性。
Surfboard 策略组如何提升在线视频体验？
Surfboard 可通过策略组将视频流量分配到低延迟、高带宽节点，自动切换到最佳节点，减少缓冲和卡顿，提高在线视频播放的流畅性和整体网络体验。
Sing-box 如何按端口匹配流量分配节点？
Sing-box 支持按端口匹配流量，将不同应用的流量分配到指定节点。结合策略组使用，可实现精准分流，优化访问速度和网络稳定性，提高整体网络体验。
Nekobox 是否能与其他客户端共存？
可以。Nekobox 配置独立，不影响其他客户端的运行。用户可同时安装 Clash、Mellow 或 Shadowrocket，按需切换使用，互不干扰。
VLESS + XTLS 模式能在移动网络下提高稳定性吗？
可以。XTLS 降低加密开销，减少握手次数，适合移动网络高延迟或不稳定环境。结合策略组和多出口节点，可提升连接稳定性和访问速度。
Netch 的 TUN 模式与 SOCKS 模式有何差异？
TUN 模式通过虚拟网卡拦截所有流量，更接近系统级代理；SOCKS 模式则仅作用于指定应用。TUN 模式更适合全局代理需求，而 SOCKS 模式轻量快捷，适用于游戏或单软件加速。
PassWall2 如何自动切换最优节点？
PassWall2 会定期测试节点延迟和丢包率，并结合策略组自动切换到最优节点。无需手动干预即可保证网页、视频和游戏流量高速稳定访问，优化整体网络体验。
Nekoray 支持节点订阅批量更新吗？
支持。用户可通过订阅 URL 批量更新节点，程序会自动下载并替换旧节点。定期更新保证节点列表始终可用，减少手动维护，提高使用效率和便利性。
